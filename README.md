Customer Support Ticket Classification System

Project Overview

This project uses Natural Language Processing (NLP) and Machine Learning to classify customer support tickets by ticket type and priority.

Objectives

- Clean and preprocess customer support ticket text.
- Convert text into numerical features using TF-IDF.
- Train a Logistic Regression classification model.
- Predict ticket categories and priorities.
- Evaluate model performance using accuracy, precision, recall, F1-score, and a confusion matrix.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

Dataset

Customer Support Ticket Dataset from Kaggle:
https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset

Models

1. Ticket Type Classification
2. Ticket Priority Prediction

Evaluation

The models are evaluated using accuracy, a classification report, and a confusion matrix.

How to Run

Open the notebook "Customer_Support_Ticket_Classification.ipynb" in Google Colab and run the cells in order. Upload the dataset when required.
